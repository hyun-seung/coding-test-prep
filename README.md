# Coding Test Preparation

Java를 활용한 자료구조 및 알고리즘 학습과 문제 해결 능력 향상을 위한 저장소입니다.

백준과 프로그래머스를 통해 주요 알고리즘 유형을 학습하고, 문제 풀이 과정에서 발견한 개선 사항과 오답을 기록합니다.

## 1. 학습 목표

- 자료구조 및 알고리즘의 핵심 개념 이해
- 문제의 제약 조건을 분석하고 적절한 알고리즘 선택
- Java를 활용한 효율적인 알고리즘 구현
- 시간·공간 복잡도 분석 및 코드 최적화
- 제한 시간 내 문제 해결 능력 향상

## 2. 학습 계획

| 기간 | 학습 내용 |
|---|---|
| 1주 차 | 배열, 문자열, 해시, 정렬, 스택, 큐 |
| 2주 차 | 완전탐색, DFS, BFS, 이분 탐색 |
| 3주 차 | 그리디, 힙, 누적합, 동적 계획법(DP) |
| 4주 차 | 혼합 문제 풀이 및 실전 연습 |

## 3. 학습 방식

1. 문제의 입력 조건과 제약 사항을 분석합니다.
2. 적절한 자료구조와 알고리즘을 선정합니다.
3. 제한 시간 내에 스스로 구현하고 검증합니다.
4. 풀이 후 시간·공간 복잡도와 다른 접근법을 비교합니다.
5. 해결하지 못한 문제는 원인을 분석하고 재풀이합니다.

### 오답 복습

- **D+1:** 다음 날 해설 없이 재풀이
- **D+3:** 접근법과 구현 방법 재확인
- **D+7:** 스스로 해결 가능한지 최종 점검

## 4. 학습 현황

| 항목 | 목표 | 진행 현황 |
|---|---|---|
| 신규 문제 풀이 | 30~40문제 | 0문제 |
| 실전 연습 | 2회 | 0회 |
| 오답 복습 | 미해결 문제 재풀이 | 진행 전 |
